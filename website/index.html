Built like a tool,
not a feed.

Everything below ships in the 7 MB binary. No accounts, no telemetry, no subscription.

  1. 01

    Block editor with Markdown shortcuts

    Headings, lists, to-dos, quotes, code blocks and dividers — type / or Markdown and the block appears. Every page keeps its history, so a bad edit is never permanent.

  2. 02

    Pages with icons, covers and favorites

    Give each page a face.

  3. 03

    Full-text search and templates

    Find any sentence you ever typed, in any page, instantly. Start from a template when the blank page stares back.

  4. 04

    Trash, history and comments

    Nothing vanishes by accident. Deleted pages rest in a trash you control; conversations stay pinned to the work.

  5. 05

    Export, backup and a sync folder

    Export everything to file at any time, and carry the same workspace across devices with a folder you already trust.

  6. 06

    Optional AI — yours, local

    Wire up a local Ollama endpoint and an assistant lives inside IdeaCraft. Off by default; it never phones home, because there is nowhere to call.

Your words,
on your disk.

IdeaCraft stores every block you write in SQLite, under your own user folder. If you reinstall it, the data stays. If you never go online, nothing breaks.

Sync works the same way: point it at a folder of your choosing (Dropbox, iCloud, a USB stick, a NAS) and the workspace travels with whatever you trust.

100% of data lives locally

One line, then you’re in.

your terminal
npm install -g ideacraft

Downloads the signed installer and installs silently for the current user — Start Menu and Desktop shortcuts, no admin rights. Requires Windows 10 (1809+) or 11.
